Tentang CineScope

Film, tanpa dibuat rumit.

CineScope adalah ruang sederhana untuk menemukan film, melihat informasi dan trailer, serta menyimpan daftar tontonan pribadi. Tanpa akun, tanpa langganan, dan tanpa klaim yang tidak perlu.

Apa yang bisa dilakukan?

CineScope mengambil katalog film dari TMDB, kemudian menampilkannya dalam tampilan yang nyaman untuk dijelajahi di ponsel, tablet, maupun desktop.

  • Melihat film yang sedang tren, populer, rating tertinggi, dan yang segera tayang.
  • Mencari film berdasarkan judul, genre, dan tahun rilis.
  • Membuka detail, pemeran, rekomendasi, serta trailer dari YouTube.
  • Menyimpan film ke Watchlist dan membuka kembali riwayat tontonan.

Tentang data dan privasi

Watchlist dan riwayat disimpan di localStorage browser Anda. Data tersebut tidak dikirim ke server CineScope karena CineScope tidak memiliki backend maupun database pengguna. Menghapus data situs di browser juga akan menghapus koleksi Anda.

Permintaan katalog dan trailer dikirim langsung dari browser ke API TMDB dan YouTube. Layanan tersebut memiliki kebijakan privasi dan ketentuan penggunaannya sendiri.

Batasan yang perlu diketahui

  • CineScope tidak menyediakan film lengkap dan tidak melewati pembatasan hak cipta.
  • Ketersediaan trailer bergantung pada data TMDB dan izin penyematan dari pemilik video YouTube.
  • Rating yang ditampilkan berasal dari TMDB dan dapat berbeda dari sumber lain.
  • API key TMDB pada situs statis dapat terlihat oleh pengunjung. Jangan gunakan key rahasia atau key produksi di deployment publik.

Atribusi TMDB

This product uses the TMDB API but is not endorsed or certified by TMDB.

Data film, poster, gambar latar, dan metadata video berasal dari TMDB. CineScope memakai TMDB API v3 dan menampilkan atribusi sesuai ketentuan TMDB. Pelajari dokumentasi API TMDB.

Pemutaran trailer menggunakan YouTube IFrame Player API. Video tetap dimiliki oleh pemiliknya masing-masing. Baca Ketentuan Layanan YouTube.
